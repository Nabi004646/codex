# Usability, admin updates and country availability

The directory preserves the established yellow theme and uses a system sans-serif font stack throughout. Opening Filters scrolls and focuses the panel below the header. Filter selections remain in place while results refresh; View results moves to the cards. Pagination has labeled 44px controls above and below the cards, disables navigation while updating, and focuses the new page of results. Reduced-motion preferences are preserved.

The admin now distinguishes the 210,052 packaged discovery listings from editable database records, drafts and published edits. The public catalog progress target is 200,000 instead of the obsolete 90,000 database target. Manual refresh shows the last successful database read. Resource and download saves read back their saved revision, keep the editor open for review, and refresh workspace totals. Public publication checks compare the public revision and content against the saved draft. New/edit dialogs have keyboard focus handling and Escape dismissal. Incomplete SEO service responses show an error instead of crashing the workspace.

A public listing can be found and converted into an editable draft. Published edits override matching discovery cards and packaged detail pages. An approved published image overrides a packaged preview. Public supplements use the selected filters and support their own bounded pagination. These reads use public, published-only policies and no-store responses. MFA, owner authorization and server publication checks are unchanged.

Country is part of the search key. Known restrictions are excluded, unchecked entries are labeled, and a separate checkbox requests confirmed availability only. India and Nepal are included in the selector. Source evidence is pinned in data/country-availability.json: Spotify signup territories and Garena's regional-edition guidance. Coverage is deliberately limited to documented provider facts; other resources remain unknown. A country choice is never treated as proof of availability, and a browser language does not choose a country or force a translation.

Validation includes the production build, existing catalog/runtime suites, new country and admin synchronization tests, desktop pagination, narrow layouts, and a local admin fixture exercising create, rename, read-back and download totals. The fixture has no real account credentials or persistent database writes and is removed before publication. A real owner-authenticated save/publish has not been performed: the connected Supabase management account exposes the portfolio project, while this site's Free-library project is different. Public Free-library RPCs were reachable and reported no published database records at inspection; private draft totals were not readable without owner authentication. No mass database import, backend policy change or new search-engine indexing claim is part of this release.
