# Application media, catalog expansion and downloads

The library now has 210,052 unique searchable entries. This release adds 10,000 distinct source-linked applications/resources and one curated GTA VI entry, preserving previous IDs and URLs.

The expansion includes 4,088 F-Droid Android apps, 2,563 Flathub Linux apps, 3,185 Apple App Store iOS apps, and 164 Kali tool documentation entries. It contains 1,816 game entries and 200 cybersecurity resources. Source collection metadata, hashes, classification counts and a sampled media audit are in data/apps-expansion-release.json. Imported entries retain Check terms labels; source catalogs and reported licenses do not imply a current provider/access/security review.

Resource cards use matching publisher screenshots, artwork, icons or original repository/video cards. The six existing genuine local screenshots remain in use. Broken or missing media renders the entry name instead of an unrelated illustration. Removed generated resource covers are no longer produced. Publisher image references remain remote. Original instructional article and worksheet illustrations are separate from application previews.

/games/gta-6 presents checked Rockstar release information, official artwork, platform details and original-source links. It links to official purchase options and does not invent a PC release or distribute game files.

/downloads lists tagged, published records from the existing protected publishing system. The private admin Download links section accepts a title, description, up to six public HTTPS download locations, platform/access notes and optional permitted image. Save a draft, reopen the saved revision, review the links and publish. Existing authenticator/grant/revision checks are retained. Files stay at their Google Drive, MediaFire or other host; no new file-upload/storage privileges were added.

Validation: production Pages build; complete repository checks; exact10k identity/URL/taxonomy/OS/media checks; source publisher-image MIME checks; browser layouts at320/390/768/1440px; genuine featured-game artwork; download editor invalid-link errors and local fixture save/review/publish. Public downloads database read returned an empty published list. No authenticated owner database writes were performed in QA.
